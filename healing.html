开放接口

内容平台可每日自动更新本站内容

心灵驿站对外提供标准 HTTP 接口。公众号、小红书、内容中台、自建 CMS 都可以按天推送图文，站点自动刷新，无需人工维护。

读取接口（公开）

无需鉴权，可直接被前端 / CDN / 第三方聚合调用。

GET/api/healing/posts图文列表（分页/分类/搜索）
GET/api/healing/posts/{id}单篇详情
GET/api/healing/meta频道元信息与分类
GET/api/healing/feed.json全量快照（便于缓存）
curl https://aimemory.cafe/api/healing/posts?limit=10

写入接口（需令牌）

内容平台每日调用 /sync 推送当日图文，幂等去重，不会重复插入。

POST/api/healing/sync批量同步（每日调用）
POST/api/healing/posts单篇新增 / 更新
POST/api/healing/upload上传配图并获取 URL
GET/api/healing/docs交互式接口文档
curl -X POST https://aimemory.cafe/api/healing/sync \
  -H "Authorization: Bearer <TOKEN>" \
  -H "Content-Type: application/json" \
  -d '{"source":"我的内容中台","posts":[
    {"title":"今天的标题","summary":"摘要",
     "content":"正文…","category":"疗愈短文"}
  ]}'
